Components

お嬢様が実装されたカスタム Web Components (Vanilla Web Components) です。再利用性と保守性を最大化し、かつ軽量な動作を実現しています。以下にプレビューとコードスニペットを表示します。

1. Glass Card (<glass-card>)

美麗なグラスモーフィズムデザインを表現するコンポーネントです。適度なブラー（blur(25px)）とソフトなシャドウを内包します。

Premium Glassmorphism

極めて美しいガラス調のサーフェスです。ライトモード、ダークモード双方において、背景と完璧に融和します。 

<glass-card reveal>
  <h4>Premium Glassmorphism</h4>
  <p>美しいガラス調のサーフェスです。</p>
</glass-card>

2. Interactive Button (<site-button>)

ユーザーのアクションを誘導するボタンコンポーネント。CTA型（背景丸がホバーで伸びる）とMore型（矢印付きのミニマル）の2タイプがあります。

CTA Type Contact Me
More Type Read Works 
<!-- CTA Type -->
<site-button href="contact.html" type="cta">Contact Me</site-button>

<!-- More Type -->
<site-button href="works.html" type="more">Read Works</site-button>

3. Section Title (<section-title>)

セクションの見出しを統一されたフォーマット（大文字＋前後のハイフン）でレンダリングします。`center` 属性で中央揃えにでき、`reveal` 属性でスクロール表示に対応します。 

<section-title title="GALLERY" center reveal></section-title>
